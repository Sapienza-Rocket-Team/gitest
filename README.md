# gitest
Git lesson exercise

## Istruzioni
1. Clona questa repo
2. Crea un branch e aggiungi un file .md chiamato come il nome del tuo dipartimento, e aggiungi il tuo username. Se il file c'è già, modificalo.
3. Fai add, commit, e push
4. Apri una pull request

Mergeremo ogni pull request fatta correttamente.
